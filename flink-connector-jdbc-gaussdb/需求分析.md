# GaussDB Flink Connector 需求分析文档

## 一、需求背景 & 概述

### 1.1 背景
- 企业数据集成需求日益增长，需要将 GaussDB 与 Flink 实时计算平台集成
- 现有 Flink JDBC Connector 对 GaussDB 支持不完善，缺乏 UPSERT 等关键功能
- MRS (MapReduce Service) 环境中存在 JAR 包冲突问题

### 1.2 目标
- 提供完整的 GaussDB Source 和 Sink 支持
- 实现 UPSERT (INSERT ON CONFLICT UPDATE) 功能
- 兼容 Flink 1.17 版本

### 1.3 范围
| 模块 | 版本 | 功能 |
|------|------|------|
| flink-connector-jdbc-gaussdb-1.17 | 1.17 | 基础功能 (Source + Sink) |
| flink-connector-gaussdb-cdc-1.17 | 1.17 | CDC 功能 (WAL 逻辑复制) |

## 四、详细流程

### 4.1 Source 读取流程

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────┐
│  Flink   │────▶│   SQL 解析    │────▶│  生成查询计划 │────▶│ 分区读取 │
│  SQL     │     │              │     │              │     │          │
└──────────┘     └──────────────┘     └──────────────┘     └────┬─────┘
                                                                 │
                    ┌────────────────────────────────────────────┘
                    ▼
           ┌─────────────────┐
           │ GaussdbDialect  │
           │ 生成 SELECT SQL │
           └────────┬────────┘
                    │
                    ▼
           ┌─────────────────┐
           │ JDBC Connection │
           │  执行查询       │
           └────────┬────────┘
                    │
                    ▼
           ┌─────────────────┐
           │ RowConverter    │
           │ 类型转换        │
           └────────┬────────┘
                    │
                    ▼
           ┌─────────────────┐
           │  Flink RowData  │
           └─────────────────┘
```

### 4.2 Sink UPSERT 流程

```
┌──────────┐     ┌──────────────┐     ┌─────────────────────┐
│  Flink   │────▶│ 数据缓冲     │────▶│ 达到阈值(数量/时间)  │
│  RowData │     │ (Buffer)     │     │                     │
└──────────┘     └──────────────┘     └──────────┬──────────┘
                                                  │
                    ┌─────────────────────────────┘
                    ▼
           ┌─────────────────────────────┐
           │   GaussdbUpsertExecutor     │
           │                             │
           │  1. 检测 URL compatibleMode │
           │  2. 选择 UPSERT 语法        │
           │     - mysql: ON DUPLICATE   │
           │     - pg: ON CONFLICT       │
           └─────────────┬───────────────┘
                         │
                         ▼
           ┌─────────────────────────────┐
           │    生成 UPSERT SQL          │
           │  INSERT INTO ...            │
           │  ON DUPLICATE KEY UPDATE ...│
           │  或                         │
           │  ON CONFLICT DO UPDATE ...  │
           └─────────────┬───────────────┘
                         │
                         ▼
           ┌─────────────────────────────┐
           │    JDBC Batch Execute       │
           │    (批量执行)               │
           └─────────────────────────────┘
```

### 4.3 CDC 捕获流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   GaussDB    │────▶│  WAL 日志    │────▶│ 逻辑解码     │
│   数据变更   │     │  (wal_level  │     │ (mppdb_      │
│              │     │  = logical)  │     │  decoding)   │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                    ┌─────────────────────────────┘
                    ▼
           ┌─────────────────────────────┐
           │   GaussDBSourceReader       │
           │                             │
           │  1. 创建复制槽 (slot)       │
           │  2. 全量快照读取            │
           │  3. 增量 WAL 消费           │
           └─────────────┬───────────────┘
                         │
                         ▼
           ┌─────────────────────────────┐
           │   解析变更事件              │
           │   - INSERT → RowData (+I)   │
           │   - UPDATE → RowData (-U/+U)│
           │   - DELETE → RowData (-D)   │
           └─────────────┬───────────────┘
                         │
                         ▼
           ┌─────────────────────────────┐
           │   发送到 Flink 下游         │
           └─────────────────────────────┘
```
